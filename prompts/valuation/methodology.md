Write the VALUATION METHODOLOGY section of a Valuation Report.

Structure:
1. Methods used: DCF (FCFF, Gordon growth + exit multiple cross-check) and relative valuation (peer multiples).
2. Data basis: which fiscal periods of historicals the projections build on.
3. Key assumptions list: WACC, terminal growth, exit multiple, projection horizon — each with its value and source (user assumption vs model default).

Rules:
- Assumptions are the user's inputs — present them as given, labelled "(assumption)".
- Max 250 words.
