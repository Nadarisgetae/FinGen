Write the DCF ANALYSIS section of a Valuation Report.

Structure:
1. FCFF build: projected revenue, EBITDA, EBIT, NOPAT, + D&A, - capex, - ΔWC = FCFF, for each projection year. Present as a markdown table.
2. Discounting: WACC, discount factors, PV of explicit FCFF.
3. Terminal value: Gordon growth TV and exit-multiple TV, both shown, both discounted to PV.
4. Bridge: EV → less net debt → equity value. (estimate)
5. Sensitivity: equity value across the WACC × terminal-growth grid. Present as a markdown table.

Rules:
- Use computed dcf_fcff and sensitivity_grid metrics directly. Do not recompute.
- Every output labelled "(estimate)".
- Max 500 words.
