Write the COVENANT ANALYSIS section of a Credit Analysis report.

Structure:
1. Covenant table (markdown): covenant, actual, limit, headroom %, breach status — per period.
2. Headroom narrative: which covenant has the least headroom and by how much.
3. Breach risk: any period where a covenant is breached or within 10% of its limit.

Rules:
- Use computed covenant_headroom metrics directly.
- If no covenant terms were provided, state that covenant analysis requires covenant inputs and show the standard thresholds used.
- Max 300 words.
