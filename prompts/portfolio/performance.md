Write the PORTFOLIO PERFORMANCE section of a Portfolio report.

Structure:
1. Returns: XIRR (annualized), absolute return and absolute return %.
2. Capital: total invested, total returned, current value.
3. Allocation: by sector and market cap (top weights).
4. Drawdown: max drawdown and duration.
5. Benchmark: excess return, tracking error, information ratio, beta, alpha — if benchmark data was provided.

Rules:
- Use computed xirr, portfolio_allocation, drawdown_analysis, benchmark_comparison metrics directly.
- XIRR is a computed figure — cite it with the cash-flow window it covers.
- Max 450 words.
