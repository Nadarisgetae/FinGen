Write the SCENARIO ANALYSIS section of a Financial Forecast report.

Structure:
1. Scenario table (markdown): bull/base/bear — key driver assumptions and resulting projected revenue/EBITDA/PAT.
2. Sensitivity: equity value or EBITDA swing per unit change in the top 2-3 drivers (tornado data).
3. Break-even: the assumption value at which the base case flips sign, if computable from the grid.

Rules:
- Use computed project_is_bs_cf (per scenario) and sensitivity_grid outputs.
- All outputs labelled "(estimate)".
- Max 300 words.
